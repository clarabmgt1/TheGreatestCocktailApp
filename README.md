# The Greatest Cocktail App 🍸

Android application developed with **Kotlin** and **Jetpack Compose**.

This app allows users to explore cocktails using the public API:
https://www.thecocktaildb.com/

## Features

- 🎲 Random cocktail
- 📋 Browse cocktail categories
- 🍹 View cocktails by category
- 🔍 Search cocktails by name
- ❤️ Save cocktails to favourites
- ⭐ Rate cocktails with personal ratings
- 🖼 Background images and improved UI

## Technologies Used

- Kotlin
- Jetpack Compose
- Retrofit
- Coil
- SharedPreferences
- TheCocktailDB API

## API

This project uses the free cocktail API:

https://www.thecocktaildb.com/api.php

Example endpoints used:

- Random cocktail
- Cocktail categories
- Search cocktails by name
- Cocktail details

## Installation

1. Clone the repository
2. Open the project in Android Studio
3. Run the application on an emulator or Android device

## APK

The final APK can be found in the `apk` folder of the project.
